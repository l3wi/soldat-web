Chosen A: an actual battlefield

The muted loop is real local gameplay, not animated artwork. The shipped version would run live attract mode: the real simulation and bots behind the menu, instead of a video. Reduced motion shows a still frame.

Walk through the revision

Loading continues automatically. Press 1–6 or click a menu option. Quick play tests regions, then counts down for three seconds; Esc cancels. Friends: 1 changes game type; 2 opens the numbered map list. Tabs jump between screens.
